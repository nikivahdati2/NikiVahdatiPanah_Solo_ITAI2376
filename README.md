# AI Study Assistant Agent

## Description
This project is an AI agent that helps students understand AI concepts in simple language.

## Problem
Many beginners struggle to understand AI concepts like neural networks and machine learning.

## Solution
This agent takes a student's question, searches study notes, and gives a simple explanation.

## Option
Single AI Agent (Option A)

## Architecture
Input → Agent → Tool (search_notes) → Tool (simple_explainer) → Output

## Tools Used
- LangChain
- Python
- Custom tools (search_notes, simple_explainer)

## How to Run
Open agent.ipynb in Google Colab and run all cells.

## Example Questions
- What is machine learning?
- Explain neural network
- What is overfitting?
